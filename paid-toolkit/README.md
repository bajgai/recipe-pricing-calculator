# Recipe Pricing Pro Toolkit — Paid Product

This folder documents the paid tool offer that can be sold through Gumroad, Payhip, Lemon Squeezy, or Stripe Payment Links.

## What buyers get

1. `pro.html` — standalone browser-based Pro calculator
2. Google Sheets workbook/spec and CSV starter templates
3. Ingredient database starter file
4. Quote history tracker
5. Customer quote generator
6. Launch/setup guide

## Suggested pricing

- Launch price: **$29**
- Standard price: **$49**
- Pro + setup review: **$99**
- Later SaaS: **$9–$29/mo** for saved cloud recipes, ingredient price tracking, reminders, and quote history

## Checkout setup

Use a simple checkout provider first:

- Gumroad: easiest for digital download
- Payhip: simple storefront + EU/UK VAT handling support
- Lemon Squeezy: polished checkout, license keys, affiliates
- Stripe Payment Link: fastest if you already use Stripe

## Delivery

Upload a ZIP containing:

- `pro.html`
- `bundle/csv/*.csv`
- `bundle/sheets/recipe-costing-bundle.md`
- `bundle/launch/first-7-days.md`

After purchase, buyers download the ZIP and open `pro.html` locally in their browser.
