# Deploy Instructions

This is a static site. Deploy the folder `digital-products/recipe-costing-calculator/` anywhere that serves HTML.

## Fastest options

### Netlify Drop
1. Zip or drag the `recipe-costing-calculator` folder into Netlify Drop.
2. Set the site name around `recipe-pricing-calculator`.
3. Share the generated URL.

### Vercel
```bash
cd digital-products/recipe-costing-calculator
npx vercel --prod
```

### GitHub Pages
1. Push this folder to a GitHub repo.
2. Enable Pages from the repo settings.
3. Use `/index.html` as the homepage.
