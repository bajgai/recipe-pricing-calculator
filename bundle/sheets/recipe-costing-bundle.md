# Recipe Costing Bundle — Google Sheets Build Spec

This is the paid product version of the free calculator.

## Workbook tabs

1. **Start Here**
   - How to use the workbook
   - Pricing formula explanation
   - Disclaimer

2. **Ingredient Database**
   - Ingredient name
   - Supplier/store
   - Package size
   - Package unit
   - Package cost
   - Cost per gram/ml/unit
   - Last updated

3. **Recipe Costing**
   - Recipe name
   - Batch yield
   - Ingredient selector
   - Quantity used
   - Ingredient cost pulled from database
   - Labor hours
   - Labor rate
   - Packaging cost
   - Overhead %
   - Total batch cost
   - Cost per unit

4. **Pricing Calculator**
   - Cost per unit
   - Target margin
   - Payment/platform fee
   - Suggested price
   - Profit per unit
   - Margin after fees
   - Wholesale price option
   - Retail price option

5. **Quote History**
   - Date
   - Customer
   - Product / recipe
   - Quantity
   - Quoted price
   - Accepted? Y/N
   - Notes

6. **Menu Margin Dashboard**
   - Product
   - Selling price
   - Cost per unit
   - Profit per unit
   - Margin %
   - Volume sold
   - Total gross profit
   - Flag: underpriced / healthy / high-margin

7. **Printable Quote Sheet**
   - Customer-facing quote template
   - Product, quantity, price, expiry date, deposit terms

## Differentiators

- Built for bakers/cafes/caterers, not generic businesses.
- Shows labor and packaging clearly.
- Includes wholesale/retail pricing.
- Tracks quote history so users learn which prices get accepted.
- Can become micro-SaaS later with ingredient price tracking and saved recipes.
